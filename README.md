# CampusShare

CampusShare adalah aplikasi peminjaman barang kampus berbasis Flutter yang memudahkan mahasiswa dan pengelola dalam melakukan proses peminjaman serta pengembalian barang.

## Fitur
- Login Admin dan Mahasiswa
- Dashboard
- Peminjaman Barang
- Riwayat Peminjaman
- Notifikasi
- Profil Pengguna

## Teknologi
- Flutter
- Dart
- phpmyadmin

## Cara Menjalankan

1. Clone repository
```bash
git clone https://github.com/USERNAME/campushare.git
```

2. Masuk ke folder project
```bash
cd campushare
```

3. Install dependency
```bash
flutter pub get
```

4. Jalankan aplikasi
```bash
flutter run
```

## Struktur Folder

```
lib/
├── models/
├── screens/
├── widgets/
├── services/
├── utils/
└── main.dart
```
